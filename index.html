Permissions & Security Modes
Control starting permission modes, tool-specific permission rules (allow, ask, deny), and permission prompt behavior. Rules evaluate in order: deny → ask → allow.
Note: auto mode is only honored in User or Managed scope.
Permission Flags
Permission Rule Lists
Deny Rules (permissions.deny) Evaluated FIRST. Matches block tool execution and hide sensitive files.
Ask Rules (permissions.ask) Evaluated SECOND. Matches always prompt the user for confirmation.
Allow Rules (permissions.allow) Evaluated THIRD. Matches auto-execute without interactive prompt.
Additional Directories (permissions.additionalDirectories) Extra working directories granted for file read/edit access.
